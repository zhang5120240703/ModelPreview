草编作品 · 六面照片

本页用于托管公开的测试照片。请先将同一件作品的六张照片放入 images 文件夹，并按下表命名。本模板不包含实际作品照片。

上传后，将下方“图片目录地址”复制到电脑上的中文测试台，选择“使用 GitHub Pages 图片链接”，自动填写六面地址。先检查链接，再手动开始生成。

图片目录地址：发布到 GitHub Pages 后显示

  • 正面：front.jpg
  • 背面：back.jpg
  • 左侧：left.jpg
  • 右侧：right.jpg
  • 顶面：top.jpg
  • 底面：bottom.jpg

照片为 JPG/PNG，每张不超过 4 MiB，宽高均为 129–4999 像素。PNG 文件可保留 .png 后缀，在本地测试台修改对应链接。

照片发布后公开可见；请只发布愿意公开的作品图片。API Key 和 backend/.env 仅保存在电脑上。

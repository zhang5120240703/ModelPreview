支持 JPG、JPEG、PNG，每张最多 __MAX_IMAGE_MB__ MB。选择后请为照片标记拍摄视角。

照片先发布到 GitHub Pages，后端继续在本机运行，无需配置本机公网地址。填写图片直链；必须有正面，其余视角可留空。

默认文件名为 front.jpg、back.jpg、left.jpg、right.jpg、top.jpg、bottom.jpg；PNG 图片请将对应链接改为 .png。照片发布后公开可见。

检查只下载并校验图片，不调用混元生成、不消耗建模额度。

每 3 秒查询一次。停止等待不会取消服务器上的建模任务。
